Anomizer Web — локальный веб-интерфейс
======================================

Запуск (Linux):
    ./anomizer-web

Запуск (Windows):
    anomizer-web.exe
    или двойной щелчок по Anomizer-Web.bat в переносимой сборке

После запуска откроется браузер с адресом http://127.0.0.1:<порт>/#<код>.
Код доступа находится в адресной строке после #; он нужен только для входа
в этот локальный интерфейс и не передаётся в сеть.

Сервер слушает только 127.0.0.1. Интернет, аккаунты и облако не используются.
Остановка: Ctrl+C в окне терминала.

Полезные параметры:
    --port 8765       порт (0 — выбрать свободный автоматически)
    --no-browser      не открывать браузер автоматически
    --temp-dir PATH   каталог для временных загрузок и экспорта

Файлы, загруженные через браузер, временные: они удаляются при закрытии
источника или остановке сервера. Исходный видеофайл никогда не изменяется.
